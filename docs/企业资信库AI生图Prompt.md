用途：用于批量生成企业资信库测试素材，包括营业执照、资质证书、人员证书、项目业绩证明、授权模板等。生成结果必须是脱敏合成样张，不得伪造真实证照、真实公章、真实编号或真实人员信息。

通用负向约束：

```text
不要真实企业名称，不要真实统一社会信用代码，不要真实证书编号，不要真实公章，不要真实身份证号，不要真实人员照片，不要真实发证机关，不要二维码，不要水印，不要明显错别字，不要卡通风格
```
